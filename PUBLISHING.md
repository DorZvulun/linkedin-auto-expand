# Chrome Web Store release checklist

- [ ] Run the browser regression checks and verify switching jobs in Chrome.
- [ ] Add extension icons to the manifest.
- [ ] Prepare the store screenshot and promotional image.
- [ ] Prepare store copy, privacy declarations, and reviewer instructions.
- [ ] Upload the extension ZIP and submit it for review.
- [ ] Publish the approved listing.
- [ ] **Replace the pending Chrome Web Store section in README.md with the real install link, commit, and push.**

The release is not finished until the README contains the published store link.
